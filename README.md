# LexTrail · 词迹

> 在任何软件里选中英文，按下快捷键，就能看到它在当前语境中的意思——并把它留进你的生词本。

**状态：规划完成，开发中。尚无可用版本。**

## 计划中的功能

- 🖱️ **随处划词**：浏览器、PDF、文档、代码编辑器……选中即查，也支持截图 OCR
- 📖 **词典 + AI**：本地词典即时给出音标、词性、释义；你自选的 AI（OpenAI 兼容服务、Ollama 本地模型等）补充当前语境下的含义、例句和翻译
- 📊 **词义按常用程度排序**：当前语境含义置顶，其他义项按常用程度排列
- ⭐ **生词本**：收藏时自动保存遇见的原句和来源
- 🧠 **科学复习**：FSRS 间隔重复算法
- 🔄 **多设备同步**：自建同步服务器，手机上通过 PWA 离线复习
- 🪶 **轻量常驻**：严格控制后台资源占用
