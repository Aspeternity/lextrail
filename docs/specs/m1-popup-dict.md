## 一、查到整词时（单词、短语）

```
launch  /lɔ:ntʃ/                        四级 六级 ★★★★
n. 下水；汽艇；发射
vt. 使下水；发射；发动
vi. 起飞；下水；投入；开始
▸ 专业释义（3）
──────────────────────────────
原句：launch missiles at ships.            来自 msedge.exe
AI 语境解析：未配置（M2 接入）
```

- **标题行**：词头、音标（ECDICT 只有一个音标，不标英 / 美）；考试标签显示为中文（中考、高考、四级、六级、考研、托福、雅思、GRE）；柯林斯星级显示为 ★，牛津 3000 核心词显示"牛津"。
- **义项**：按原文顺序，每个词性一行，同一词性的义项用"；"连起来。数据里每个义项仍是独立的一条，M2 的 AI 排序（D019）不受影响。
- **截断**：普通释义全部显示；带领域标记的释义（[计]、[医] 等）默认折叠为"▸ 专业释义（N）"，点击展开；内容超出 380×260 时正文区域可滚动，窗口大小不变，标题行和底部的原句、来源固定。
- **变形词**：两个词条都有时，第一个标题写成"better（good 的比较级）"，第二个是"good"，每个词条显示前 3 个词性行，多出的点"▸ 更多"展开；只给原形时（launched），原形词条上方加一行灰字"launched 是 launch 的过去式、过去分词"。
- **首字母大写、有两个词条**（The / the）：两个都显示，小写在前。
- **原句**：最多 2 行，超出省略；只在 UIA 取词时有。

## 二、带连字符的复合词拆开时

```
self-attention
词典没有整词，以下是各部分的释义
self  /self/       n. 自我；自身；本人 …
attention  /ə'tenʃən/   n. 注意力；关心 …
未收录：xxx
```

每个部分只显示第一个词性行，最多 2 行，超出省略；部分本身是变形时也带关系说明（"models（model 的复数）"）。

## 三、其他情况

- 词典查不到：原文 + "词典中没有收录" + 灰色"AI 语境解析：未配置（M2 接入）"。
- 句子：原文（最多 4 行）+ "句子翻译需要 AI（M2 接入）"。
- 没有英文字母：标题"目前只支持英文"（D045）。

## 四、接入方式

1. 顺序：取词 → 行末连字符判断（整词查询 + 方案 A 词头表，D044 补充）→ 规范化 → 分类（D045）→ 查词典（`lookup_with_parts`），都在取词线程里完成，结果放进发给页面的内容（`Content::Selection` 扩展）。查词只需几毫秒。
2. 方案 A 词头表：同一词典文件里的新表 `extra_words`（dict-builder 生成，`FORMAT_VERSION` 1 → 2）；判断合并时先查精简版整词，再查这张表（也走后缀规则）。
3. 词典文件位置：作为 Tauri 资源（开发构建和 `tauri build --no-bundle` 都会复制到可执行文件旁）；第一次查词时才打开，只有托盘时不打开；缺失或格式不对时悬浮窗提示"词典文件缺失"并写日志，取词照常。
4. CI：Windows job 构建桌面程序前先生成词典（数据有缓存，只多一次几秒钟的生成）。
5. 不在这次范围：查询历史接入（下一项）、收藏 / 发音按钮（M3 / M5）。
