## M0 · 项目骨架与性能原型

目标：搭好项目结构，并用实测数据验证"路线 A（Tauri/WebView 悬浮窗）"是否可行（D008、D009）。

- [x] 初始化 monorepo：Cargo workspace、pnpm workspace、目录结构（见 `ARCHITECTURE.md` 第 3 节）
- [x] 代码规范：`rustfmt`、`clippy`、TypeScript strict、ESLint、Prettier
- [x] GitHub Actions：每次推送自动运行格式检查、lint、测试、Windows 构建
- [x] Tauri 2 桌面应用骨架：托盘图标、托盘菜单、开机不显示窗口
- [ ] 全局快捷键注册，注册失败时提示
- [ ] 设置的读写（本地配置文件），API Key 存入系统凭据管理器
- [ ] 悬浮窗：单独打包的轻量页面；在鼠标附近显示；Esc / 点击外部关闭
- [ ] 悬浮窗生命周期：隐藏 → `TrySuspend` 挂起 → 快捷键 `Resume`；低内存通知时销毁；"内存优先"模式
- [ ] 主窗口骨架：关闭时销毁
- [ ] **性能测试**：按 `ARCHITECTURE.md` 第 10 节逐项实测，包括"挂起 2 小时后恢复"，输出报告到 `docs/specs/m0-benchmark.md`
- [x] 单实例：第二次启动时直接退出（以后改为唤起主窗口）（新增）

**完成标准**：性能报告完成，并在 `DECISIONS.md` 中记录"路线 A 确认"或"切换到路线 B"的结论。

## M1 · 取词与词典（可以离线查单词）

- [ ] `lextrail-capture` 统一接口 + Windows 实现：UI Automation 取词（含上下文）
- [ ] 剪贴板兜底：修饰键等待、序列号确认、恢复原内容、终端使用 Ctrl+Insert
- [ ] 连按两次 Ctrl+C（默认关闭）：剪贴板变化监听、50–500 ms 判定、UIA 补充上下文
- [ ] 来源软件识别（进程名 / 窗口标题）
- [ ] `tools/dict-builder`：ECDICT → 精简版 SQLite；义项拆分；索引
- [ ] `lextrail-dict`：查询、词形还原、单词 / 短语 / 句子分类
- [ ] 悬浮窗显示词典结果：音标、词性、释义、考试标签
- [ ] 快捷键设置界面与冲突提示；整理常用软件快捷键清单，确定默认快捷键（D014）
- [ ] 查询历史写入本地数据库
- [ ] 单元测试：词形还原、义项拆分、输入分类、剪贴板连按判定

**完成标准**：在浏览器、PDF 阅读器、Word、VS Code、终端中都能用快捷键查词，词典结果在 100 ms 内显示。

## M2 · AI 语境理解

- [ ] `lextrail-ai` 适配器接口 + OpenAI 兼容实现（含 Ollama）
- [ ] 多服务商配置界面、测试连接按钮
- [ ] 按任务分配模型（查词 / 句子翻译）
- [ ] 默认提示词：附带词典释义和上下文；语境含义、解释、例句、义项排序
- [ ] 分段标记流式解析器（容错）+ 悬浮窗流式渲染
- [ ] 词义排序显示：语境含义置顶；三档标注；统一排序 / 按词性分组设置
- [ ] AI 结果缓存（语境解析、词义排序分开缓存）
- [ ] 悬浮窗"换一个模型重新解析"
- [ ] 超时 / 出错时自动切换备用模型
- [ ] 句子翻译与难词标注
- [ ] 首次启动引导：选择服务商、填写 Key、可跳过；未配置时悬浮窗显示灰色提示
- [ ] 高级设置：编辑提示词
- [ ] 单元测试：流式解析器（含各种格式偏差）、缓存键

**完成标准**：配置任意一个 OpenAI 兼容服务商后，查词时能在词典结果之后流式显示语境解析和排序后的义项。
